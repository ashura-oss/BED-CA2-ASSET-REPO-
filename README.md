# BED CA2 Runtime Assets

Static runtime assets for the BED CA2 game.

The application repository keeps a local `public/assets` copy for offline development. Deployed game pages load this published bundle through GitHub Pages:

`https://ashura-oss.github.io/BED-CA2-ASSET-REPO-/assets/...`

Only publish browser-ready assets here: WebP images, WebM audio, GLB models, and their runtime JSON metadata. Do not put credentials or private files in this repository.
